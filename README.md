# promo-code-demo

Небольшой демо-проект: поле ввода промокода на странице оплаты.

## Структура

```
src/
├── checkout/
│   ├── PromoCodeField.js          # компонент поля промокода
│   └── __tests__/
│       └── PromoCodeField.test.js # тесты компонента
└── ui/
    └── FieldError.js              # хелпер для сообщений об ошибках под полем
```

## Запуск

```bash
npm install
npm test
```

Тесты используют Jest с окружением jsdom. Дополнительных зависимостей не нужно.
